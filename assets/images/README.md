# Image assets

Drop the following files into this folder. Names must match exactly (case-sensitive on Linux/macOS):

| File name | Source / contents | Where it appears |
|---|---|---|
| `logo.jpg` | "[PM3] Group Project.jpg" — RePaws logo (PNG with transparent background preferred for cleaner footer rendering) | Top nav |
| `product-shampoo.jpg` | 25.jpg — Pineapple Shampoo bottle | Hero, card 01, modal |
| `product-spray.jpg` | 26.jpg — Nourishing Pet Spray bottle | Card 02, modal |
| `product-balm.jpg` | 27.jpg — Pineapple Pet Balm jar | Card 03, modal |

## Recommended specs

- **Logo**: PNG (transparent) or SVG. ~360 × 120 px for the dark/light header.
- **Product shots**: JPG/PNG, square (1:1) or 4:5 portrait. 1000–1600 px on the long edge.
- Keep file size under 400 KB each (compress with TinyPNG or similar) for fast page load.

If a file is missing, the logo gracefully falls back to an inline SVG mark and the product
image area renders as an empty box — refresh after copying the files in.
